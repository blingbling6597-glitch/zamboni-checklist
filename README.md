# 洗冰檢點表電子化

冰上樂園洗冰指揮官(值班)作業安全防護檢點表的電子化專案。同仁用手機填 Google 表單，資料自動進 Google 試算表，試算表裡就是統計分析後台。

## 運作方式

```
手機填 Google 表單 ──送出──▶ Apps Script 觸發器 ──▶ 試算表「明細」「每次紀錄」
                                                     │
                                                     ▼
                              總覽／項目分析／人員分析／趨勢分析／時段分析（公式即時更新）
```

- **填報方式**：每次洗冰結束後，由值班洗冰指揮官填一份，逐項勾選四位當班人員有沒有做到（跟紙本一樣）。
- **表單結構**：第 1 頁填日期、時間、填表人和四位人員（從人員名單下拉選），後面四頁依角色分頁，每頁再依三個階段分段。全部 48 題，★ 標示 18 個重點項目（原表橘底）。
- **後台分頁**

| 分頁 | 內容 |
| --- | --- |
| 總覽 | 累計次數、整體／重點／近 7 天／本月達成率、最常未做到前 10 項、最近 10 次紀錄 |
| 項目分析 | 48 項各自的檢核次數、未做到次數、未做到率（色階＋長條圖），可篩選角色、階段、重點 |
| 人員分析 | 每位同仁的達成率、依角色拆開的達成率、重點項目達成率、各人未做到的項目 |
| 趨勢分析 | 每日／每週／每月達成率與圖表、每月 × 角色 |
| 時段分析 | 各整點時段、時段 × 角色、星期別達成率 |
| 每次紀錄 | 一次洗冰一列：人員、未做到項數、達成率、未做到項目清單、備註 |
| 明細 | 一題一列的長表，所有分析的來源；也可以自己拿去做樞紐分析 |
| 人員名單 | 表單下拉選單的姓名來源 |

## 安裝步驟（約 10 分鐘）

1. 在 Google 雲端硬碟新增一份空白 **Google 試算表**，命名例如「洗冰檢點後台」。
2. 選單 **擴充功能 → Apps Script**。
3. 在 Apps Script 編輯器：
   - 把預設的 `程式碼.gs` 內容換成 `apps-script/Config.js` 的內容，並把檔名改成 `Config`。
   - 按「＋ → 指令碼」再新增 `Core`、`Setup`、`Analysis` 三個檔案，分別貼上同名 `.js` 的內容。
   - 左側「專案設定」勾選「在編輯器中顯示 appsscript.json」，把內容換成 `apps-script/appsscript.json`（設定台北時區）。
   - 按儲存。
4. 回到試算表，重新整理頁面，上方會出現 **「洗冰檢點」** 選單。
5. 按 **洗冰檢點 → ① 初始化／建立表單**。第一次會要求授權，用你的帳號同意即可。
6. 它會建立「人員名單」分頁並提示你先填姓名。在 A 欄一格填一位同仁，再按一次 **① 初始化／建立表單**。
7. 跳出的視窗就是表單連結。把「同仁填寫用」連結傳到群組，或做成 QR Code 貼在洗冰室，手機掃了就能填。

> 如果是公司的 Google Workspace 帳號，可以在表單設定裡開「僅限機構內使用者」，避免外部人員填寫。

## 日常操作

| 情況 | 做法 |
| --- | --- |
| 人員異動 | 改「人員名單」分頁 → **更新表單的人員選單** |
| 忘了表單網址 | **顯示表單連結** |
| 有人改到明細、或懷疑資料漏掉 | **重新計算全部資料**（從表單原始回覆重算） |
| 分析分頁被改壞 | **重建分析分頁** |

## 表單改版（例如 11509-2 → 下一版）

1. 修改 `apps-script/Config.js`：
   - `FORM_VERSION` 改成新版號。
   - 題目文字沒變或只修錯字 → **保留原編號**，跨版本統計才能接起來。
   - 新增題目 → 給新編號。
   - 刪除題目 → **不要刪掉那一行**，加上 `retired: true`。
2. 把新的 Config 貼回 Apps Script，按 **改版：建立新版表單**。舊表單會停止收件並顯示「請改用新版」，舊資料保留，「明細」的「表單版本」欄可以區分新舊版。
3. 新表單連結要重新發給同仁。

## 目錄

| 路徑 | 說明 |
| --- | --- |
| `原始表單/` | 紙本表單原檔（Excel、PDF）。改版時直接覆蓋並 commit，用 git 歷史比對差異 |
| `apps-script/Config.js` | 題目設定（由原始 Excel 產生，48 題） |
| `apps-script/Core.js` | 把一筆回覆轉成明細列的純邏輯 |
| `apps-script/Setup.js` | 選單、建立表單、接收送出、重算 |
| `apps-script/Analysis.js` | 建立分析分頁與圖表 |
| `tests/core.test.js` | 核心邏輯測試：`node --test tests/core.test.js` |
